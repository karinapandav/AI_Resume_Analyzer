# 🤖 AI Resume Analyzer

An AI-powered Resume Analyzer built with **n8n** and **Google Gemini** that extracts text from PDF resumes and generates structured ATS-based feedback.

---

## 🚀 Features

- 📄 Upload Resume (PDF)
- 📝 Extract text from PDF
- 🤖 AI-powered resume analysis using Google Gemini
- 📊 ATS Score Generation
- 💼 Professional Summary
- 🛠 Skills Detection
- ✅ Strengths Identification
- ⚠ Weakness Detection
- 📈 Missing Skills Analysis
- 💡 Resume Improvement Suggestions

---

## 🏗 Tech Stack

- **Automation:** n8n
- **LLM:** Google Gemini
- **Document Processing:** PDF Text Extraction
- **Frontend:** React + Vite *(Coming Soon)*
